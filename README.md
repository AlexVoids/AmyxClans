# AmyxClans 2.0.0 — кланы AmyxCraft

Доработка предоставленного **AmyXClans 1.4.3**, с сохранением его данных и публичного API. Техническое имя плагина остаётся `AmyXClans`: его использует ChatPerms. Репозиторий и PHAR называются AmyxClans.

PocketMine-MP API **5.28+**, PHP **8.2+** (у пользователя PHP 8.3.29 / NG 5.39.1). Только Bedrock/PocketMine, без Vault и Java.

## Установка и обновление

1. Полностью остановите сервер. Скопируйте `plugin_data/AmyXClans`, `AmyxEconomy`, `ChatPerms` и боевые миры в резервную копию. На некоторых сборках папки данных находятся внутри `plugins`.
2. Замените старый клановый PHAR на `AmyxClans.phar`. Не оставляйте одновременно две версии AmyXClans.
3. Из комплекта установите **AmyxEconomy 1.0.2** и **ChatPerms 1.5.6** вместо старых PHAR. Их папки данных сохраняйте. Экономика обновляет существующую SQLite, добавляя таблицу идемпотентных операций; счета и валюта сохраняются.
4. Оставьте официальный **FormAPI 2.1.1**. Для голограмм тотемов нужен **AmyxHologram 1.0.2** из вашего набора. При отсутствии голограмм осада работает, но подписи над выпавшими тотемами отсутствуют.
5. Если у вас установлены **AmyBuilderGuard** и **AmyxCommandAccess**, замените их на версии **1.3.2** и **1.0.1** из комплекта. Они закрывают обход регионов через WorldEdit/undo и добавляют `/clan` в прежний белый список. Другие команды игрокам не открываются. Эти два плагина ставьте только при наличии их старых версий.
6. Запустите сервер. Проверьте сообщения о миграции и откройте `/clan`. Настройте арены через `/clanadmin`, затем проведите пробный бой на копии мира.

Автоматическая копия исходных YAML создаётся в `AmyXClans/backups/pre-v2-ДАТА/`. Основной файл остаётся `clans.yml`, индекс `players.yml` пересоздаётся из членов кланов. Сохраняются казна, участники, статистика, роли, значки, NBT предметов, каналы, заявки, приглашения и старая история. Старые приоритеты переводятся в 1–10; лидер единственный получает 10. Первая старая точка становится основной, остальные сохраняются в `legacyHomes`; исходное содержимое хранилища дополнительно архивируется в `legacyStorage`. Архив не является вторым доступным инвентарём. Покупка дополнительных домов отключена, поскольку новая модель допускает одну точку; старые параметры домов сохранены в конфиге для совместимости резервных копий.

Не возвращайте старый PHAR поверх мигрированных данных. Для отката остановите сервер и восстановите **весь согласованный комплект** резервных копий экономики, кланов, игроков и миров. Отдельный откат денег может нарушить выполненные переводы.

## Возможности

- `/clan`: создание, приглашения/заявки, участники, передача лидерства, роли и права, казна, улучшения, общее хранилище, одна точка, регионы, история, рейтинг и битвы.
- Лидер 10 неизменяемый; заместитель 9 и участник 1; пользовательские роли 1–9. Права проверяются при выполнении, включая ответы на устаревшие формы. Каждая форма обрабатывается однократно. Права лидера отображаются только для чтения: Bedrock не поддерживает выключенные переключатели FormAPI.
- Вступление и создание после 1200 секунд игры. Используется `AmyxStats::getStatistic(..., playtime_seconds)` при наличии; иначе собственный UUID-учёт авторизованного времени. Уже состоящие в кланах игроки не исключаются миграцией.
- 5 уровней, по 1000 XP; избыток переносится через несколько уровней, на пятом рост прекращается. XP за бои/убийства/участие настраивается. Чтобы первый уровень мог развиваться до допуска к войнам, действует событие активности: 50 XP за час движения участника, максимум 4 начисления в сутки на UUID и клан. Повторный ID события не начисляет XP.
- Рейтинг: уникальное вступление +2, победа +40, поражение −40, техническое −30; начальное значение и отрицательный рейтинг настраиваются. Старый вычисляемый рейтинг сохраняется при миграции как исходное число.
- Казна использует монеты AmyxEconomy; пополнение сначала погашает долг. Двухсторонние переводы восстанавливаются по журналу с идемпотентным SQLite API. Во время матча закрыты переводы, покупки, изменение ролей, регионов и выход из клана.
- Значки, переименование, прежнее расширение числа участников, расширения регионов. Бонус региона — **суммарные** +2/+4/+6/+8/+10, а не сумма купленных ступеней. Размер уже созданного региона не увеличивается автоматически при повышении уровня; увеличиваются лимиты новых регионов. Для старого региона доступно отдельное подтверждение «Применить размер уровня» с проверкой соседних территорий.
- Полновысотные регионы с доступом по ролям, защитой строительства/контейнеров/огня/взрывов. Проверяется пересечение с другими кланами, аренами, AmyBuilderGuard и заданными границами мира. Другие защиты никогда не отменяются.
- Общее старое хранилище сохраняет NBT. Одновременно открывается одно окно на клан; временные сундуки убираются при закрытии и восстанавливаются после сбоя по сохранённым координатам.
- `#c сообщение`: только свой клан, роль и ник. Старые `#название сообщение` продолжают работать с приоритетами каналов. ChatPerms сохраняет глобальный/локальный чат, группы, nametag и значки платформ; отменённые события клановому каналу не доставляются.

## Битвы

Арена и осада используют заявки, команды 3/5/10/15, сбор 600 секунд, подготовку 300 секунд и бой 1800 секунд. По умолчанию нужны уровень 2 и 4 региона. После принятия сначала сохраняется карта; **полные 10 минут сбора** начинаются после готовности снимка.

Игрок входит через форму и занимает отдельную точку. Режим Survival, собственные предметы и броня, без наборов и замены инвентаря. До начала нельзя двигаться, атаковать и строить, стороны разделены стеклянной стеной. В бою нельзя выходить за границу, телепортироваться или менять режим игры; команды ограничены `/clan`.

В обычном бою смерть/выход — выбытие. При смерти срабатывают обычные серверные выпадения предметов, даже при keepInventory; снимки инвентаря не выдаются и не восстанавливаются. Последний погибший завершает бой, таймер сравнивает выживших. Одновременное уничтожение даёт ничью. Выжившие и выбывшие возвращаются домой или на спавн; если точка попадает в зарезервированную боевую зону, используется безопасный выход.

В осаде **нажмите на вражеский специальный сундук**, чтобы взять тотем; затем **нажмите на свой сундук с тотемом в активной руке**, чтобы доставить его. Это серверные точки цели: обычный интерфейс этих сундуков закрыт, сам тотем не хранится в обычном контейнере и недоступен воронкам. Визуальный предмет — подписанная звезда Незера, чтобы обычная механика тотема бессмертия не потребляла цель. Нужен свободный слот горячей панели.

Носитель замедлен и помечен фиолетовыми частицами: переносимого между всеми клиентами эффекта Glowing в PM5 нет. Смена активного слота, смерть и выход сбрасывают тотем; собственный тотем поднимать нельзя. Перемещения через курсор/контейнеры/крафт отменяются, посторонние экземпляры метки удаляются. Над выпавшим тотемом используется временная голограмма AmyxHologram.

В обоих режимах выбывшие не возвращаются в бой. В осаде победа наступает при доставке; при истечении времени по умолчанию побеждает защитник B. Убийство всех противников само по себе не заменяет цель осады.

Несбор: −30 рейтинга и штраф 10000; доступная казна списывается, остаток становится долгом. Штраф −40 дополнительно не применяется. Если не собраны обе стороны — техническое поражение обеим, без победителя. Победный XP за технический исход не выдаётся. Повторные бои между теми же кланами по умолчанию ограничены 30 минутами; XP убийств защищён задержкой пары и запретом одинакового IP (настраивается).

### Восстановление карты и предметы

До изменения стены сохраняются устойчивые Bedrock block states и NBT блок-сущностей. Чанки матча закрепляются до завершения восстановления. Снимки создаются и применяются порциями, стадия/участники/награды/возвраты сохранены. Перезапуск закрывает незавершённый бой без повторной награды; арена остаётся занятой до восстановления. При недоступном мире снимок сохраняется для последующего восстановления.

Контейнеры карты во время боя закрыты, контейнеры нельзя разбивать; блоки арены не дают предметов или XP. Это предотвращает получение дубликатов ресурсов при восстановлении карты. Своими вещами можно пользоваться, а выпавшую экипировку подбирают живые участники. Неподобранные обычные вещи при завершении перемещаются к настроенной точке выхода, вместо удаления или возврата в инвентарь.

Для осады своего региона OP может привязать арену к региону защитника. Снимок охватывает всю площадь и высоту региона. Опция `war.siege-transfer-region` по умолчанию выключена; при включении захваченный регион передаётся атакующему, если его уровень и лимит позволяют, а регион не отмечен застрахованным. Страхования в исходном 1.4.3 нет; существующая метка `insured` учитывается без создания новой страховой валюты. После смены владельца OP должен перепривязать арену.

## Файлы и настройки

- `config.yml`: экономика, цены, уровни/XP, рейтинг, время, регионы, права по умолчанию, функции, формы и цвета.
- `interface.yml`: замена текстов новых форм/сообщений; справа укажите свой текст. Существующий `texts.yml` сохранён, его замены применяются поверх новых.
- `messages.yml`: сообщения возвращения после смерти.
- `arenas.yml`: конфигурации карт; [инструкция](docs/ARENAS.md).
- `clans.yml`: кланы и согласованное состояние матчей/журналов; не редактировать на запущенном сервере.
- `snapshots/`: незавершённые снимки; **не удалять**, пока бой/восстановление не закрыт.

`/clanadmin` открывает настройки только реальному OP. Выданного `amyxclans.admin` недостаточно. Консоль доверенная. Сохранены `/clanadmin reload`, `setbank <клан/id> <сумма>`, `money <игрок> <сумма>`, `delete <клан/id>`; добавлен `xp <клан/id> <сумма>`. Удаление архивирует клан, активный матч и незаконченный перевод блокируют удаление.

Права: `amyxclans.command` — обычное меню, `amyxclans.admin` — видимость технической команды (выполнение всё равно проверяет OP). Ролевые права независимы от permissions сервера.

## Проверка и сборка

[Аудит](docs/AUDIT.md), [проверки и ограничения](docs/TESTING.md). Серверные пробы используют настоящий PocketMine и заменяют только игрока/сетевой транспорт тестовыми объектами. Они не являются тестом настоящих клиентов Bedrock или полной сборки NG 5.39.1.

```bash
php -n -d phar.readonly=0 tools/build.php
python3 tools/test-server.py --php /path/to/php --pmmp /path/to/PocketMine-MP.phar --formapi /path/to/FormAPI.phar --hologram /path/to/AmyxHologram.phar --integrations
```

Обязательные зависимости: AmyxEconomy 1.0.2 и FormAPI. ChatPerms 1.5.6 — подтверждённая интеграция вашего чата. AmyxStats и SimpleAuth используются при наличии. Весь исходный PHP и дополнения находятся в этом репозитории. Готовые PHAR и архивы — в GitHub Releases.
