AmyxClans 2.0.1 — исправление числовых ID арен и новые настройки доступа.

- Исправлен TypeError при открытии арены с ID 11 и другими числовыми ID.
- Добавлена /clanhome: общая точка клана, проверки авторизации и запрет выхода из боя.
- Для каждой роли в каждом регионе отдельные права: разрушение, строительство, контейнеры, взаимодействие с блоками и сущностями. Старые общие разрешения сохранены.
- Лимит каналов поднят до 5 с автоматическим обновлением существующего конфига.
- Обновлены интеграции AmyBuilderGuard 1.3.3 и AmyxCommandAccess 1.0.2: независимые права WorldEdit и видимость /clanhome.

Скачать AmyxClans-v2.0.1-install.zip. Замените AmyxClans.phar и, если установлены, оба плагина из optional/. Папки данных сохраняйте. AmyxEconomy 1.0.2, ChatPerms 1.5.6 и официальный FormAPI остаются прежними.

Пройдено 108 серверных проверок: 36 сценариев на каждом из трёх тестовых вариантов ядра.

Полные исходники — AmyxClans-v2.0.1-source.zip. Проверки перечислены в docs/TESTING.md; настоящие клиенты Bedrock и полная NG 5.39.1 требуют проверки на игровом стенде.
