# Аудит входных проектов, 24.10.2026

Исходный AmyXClans 1.4.3: API 5.0.0, PHP strict_types, один Main.php (2571 строка), EconomyBridge и собственные формы. В коде используются возможности PHP 8; рабочая среда пользователя — PHP 8.3.29, NG-PocketMine-MP 5.39.1. Минимальный целевой PHP 8.1, API 5.

Есть /clan (/c, /clans), /clanadmin, создание, приглашения, заявки, участники, роли с приоритетами 0–100, передача лидерства, общий виртуальный двойной сундук, несколько домов, пользовательские каналы, переключение PvP/видимости, покупка значков/лимитов/переименования, казна, история последних 100 операций. Рейтинг вычислялся из убийств, смертей и числа участников. Уровней, XP, регионов, войн, долга и арен нет.

Данные: clans.yml → clans, players.yml → players. Предметы хранилища — сериализованный NBT. Важно сохранить идентификаторы кланов и ролей, имена/индекс игроков, членов, балансы, предметы и их NBT, купленные значки (включая ресурс-паковые коды), лимиты, дома, каналы, заявки/приглашения, настройки, статистику и старую историю. Перед миграцией создаётся отдельная копия исходных файлов. Дополнительные дома архивируются; активной остаётся одна точка. Валюта не заменяется.

ChatPerms 1.5.5 подтверждён пользователем. API 5.0.0; /cp и административные подкоманды, группы/права/временные группы, локальный и глобальный чат, задержки, платформенные значки, nametag и временный текст над игроком. config.yml хранит настройки групп/игроков. Обычный обработчик уже пропускает сообщения с #. Клановые метки получает через публичные методы AmyXClans. Поэтому техническое имя AmyXClans и публичные методы имён/ролей сохраняются. Дополняется именно ChatPerms: отдельное делегирование #c после обычных проверок событий, без повторной доставки.

AmyxEconomy 1.0.1: SQLite accounts и transactions, целочисленные монеты. Проверены публичные ensureAccount/getBalance/deposit/withdraw/setBalance/transfer. Казна остаётся отдельным клановым балансом. Для восстановления переводов после сбоя расширяется существующий API идемпотентной операцией, с дополнительной таблицей в той же SQLite, без смены БД и потери счетов.

FormAPI 2.1.1: официальные классы jojoe77777\FormAPI, обязательная зависимость вместо самописного протокола форм. У Bedrock нет неактивных переключателей: права лидера показываются только для чтения. AmyxHologram 1.0.2 используется для временных голограмм тотемов через проверенный менеджер сущностей. AmyxStats, если установлен, предоставляет playtime_seconds; иначе нужен собственный UUID-учёт.

Архитектура обновления: атомарное YAML-хранилище и миграция; управление кланами/ролями/XP/рейтингом; финансовый журнал; регионы/доступ; время игры; история; FormAPI-интерфейсы; заявки/арены/конечный автомат матчей; снимки карты; тотемы; телепортация; чат; слушатели защиты. Старое хранилище предметов выделяется из монолита. Настройка арен и технические операции дополнительно проверяют Server::isOp, независимо от выданных permission nodes.

Нужны проверки на настоящем клиенте: формы/контейнеры на поддерживаемых версиях Bedrock, PvP и доставка тотема несколькими игроками, визуализация голограмм, взаимодействие с прочими защитами. Статические и серверные проверки не заменяют сетевой тест на NG 5.39.1.
